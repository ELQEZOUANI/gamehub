# Game Hub

Minimalist Flutter game hub with a mint theme and smooth micro‑animations.

What’s inside
- Revamped Home: glassmorphism hero, quick actions, trending carousel
- Animated buttons and subtle transitions across flows
- Profile stats: Tic‑Tac‑Toe, 2048 bests, Rock‑Paper‑Scissors results
- New game: Rock • Paper • Scissors

Run
```bash
flutter pub get
flutter run
```
